# Things only a running game can confirm

Part of the DayZ static analysis notes (see `README.md` in this folder for the map). Nothing in this project was executed, so every number below is read from the shipped scripts, configs and executable. This list is the set of statements where a mistake would matter most or where I had to infer something. Each entry says what to look at in the game and what the notes predict, so a result either confirms the note or shows exactly which line to correct.

**How to use it.** Use a private (offline or local) server and your own test character; the tests below only observe or use ordinary gameplay. Admin or developer tools help but are not needed. Record the result in the last column and fix the cited section if it differs. Entries are ordered by how much they matter.

## Notes on running the tests

- Where a test needs a rare condition (heat stroke, a crash at a given speed), a debug or admin tool that sets the condition is fine; it only has to produce the same state a player would reach.
- Several predictions are statistical (V10, V12, V18); a small sample can only reject a wrong prediction, not prove a right one.
- If a result differs, the cited section lists the file and function the number came from; check those first, then correct the note and mark the original statement [obs] (if the code read was the issue) or move it to [?].
